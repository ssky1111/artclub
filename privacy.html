プライバシーポリシー

制定日：2026年8月10日

ARTCLUB（以下「本サービス」）は、ドローイング練習のための Web アプリです。 取得する個人情報は必要最小限に抑え、練習と投稿に必要な範囲でのみ扱います。

1. 取得する情報

ログイン時

X（Twitter）または Google のアカウントでログインできます。 認証は Supabase Auth を通じて行い、サービス提供に必要な範囲で ユーザー ID・メールアドレス等を保持します。 OAuth 連携で、あなたのタイムラインへ勝手に投稿したり、不要な情報を取得したりしません。

プロフィール

任意で設定するユーザーネームを保存します。公開スケッチなどに表示されます。

投稿したスケッチ

あなたが保存・公開したスケッチ画像と、それに付随する情報 （お題 ID、公開／非公開、模写の可否、表示名、作成日時など）を保存します。 公開設定にしたスケッチは、他の利用者のアトリエや作品ページなどで表示されます。

いいね

どのスケッチにいいねしたかを記録します。

端末内だけに残る情報

練習の履歴、ふりかえりの言葉、描画の下書き、見た目や音の設定などは、 原則としてこの端末のブラウザ内（localStorage / IndexedDB）にだけ保存します。 これらをサーバーへ自動送信することはありません。

2. 利用目的

  • ログイン状態の維持と、メニュー・保存機能の提供
  • スケッチの保存・公開・削除、いいねなどの機能提供
  • お問い合わせへの対応
  • 不正利用の防止とサービスの安定運用

3. 第三者提供

法令に基づく場合を除き、本人の同意なく個人情報を第三者に販売・提供しません。 サービス運営のため、次の事業者に処理を委託・連携することがあります。

  • 認証・データベース・画像保存：Supabase
  • ログイン連携：X（Twitter）、Google
  • フォント配信：Google Fonts
  • お題写真・図版の取得（利用時）：Unsplash、Wikimedia Commons など

4. Cookie・アクセス解析

広告や行動追跡を目的とした Cookie・解析ツールは使っていません。 ログイン状態などは、端末内の保存領域を使って維持します。

5. 保存期間と削除

アカウントや投稿に紐づく情報は、利用が続くあいだ保持します。 公開・保存したスケッチは、アプリ内の削除操作で取り除けます。 アカウント全体の削除や、端末外データの消去を希望する場合は、下記までご連絡ください。

6. 安全管理

通信は HTTPS で行い、認証トークンなどは端末側でも取り扱いに注意しています。 ただしインターネット上の完全な安全を保証するものではありません。

非公開に設定したスケッチは一覧などからは隠しますが、 画像ファイルの URL を知っている場合に閲覧できる可能性がある点にご留意ください。

7. 開示・訂正・利用停止

保有する個人情報の開示・訂正・削除などを希望される場合は、お問い合わせください。 本人確認のうえ、合理的な範囲で対応します。
