# Croqui — 毎日3分のデッサン練習

「うまくなりたいのにクロッキーも模写もやらない」を解くためのアプリ。
やる気を出させることではなく、**やる気がない日でも1分で始められて、始めたら勝手に効く練習になっている**ことを狙っている。

- ワンタップで写真が出てタイマーが走る（最短メニューは3分）
- 写真の**見せ方を変える**ことで、鍛えたい観察スキルだけを強制的に使わせる
- 手・脚など「見ても描けない部位」には、**日本語の構造レッスン**と著作権切れの解剖図版が付く
- 終わったら20秒のふりかえり。連続日数と積み上げが残る
- ビルド不要の静的サイト。データは全部この端末の中（サーバーなし）

## つかいかた

```bash
# どれでもいい。file:// だと ES モジュールが読めないので簡易サーバー越しに開く
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages に置く場合は、リポジトリの Settings → Pages で `main`（またはこのブランチ）の
ルートを指定するだけ。ビルド工程はない。

スマホでは、ブラウザで開いてから「ホーム画面に追加」すると PWA として全画面で立ち上がる。

## お題の写真をどこから持ってくるか

設定画面で3つから選ぶ。

| 取得元 | キー | ジャンル指定 | 備考 |
| --- | --- | --- | --- |
| **Unsplash** | 必要 | できる | 本命。人物ポーズ／手／布のしわなど狙って出せる |
| **Lorem Picsum** | 不要 | できない | とりあえず動かしたいとき用。中身はランダム |
| **端末内の画像** | 不要 | — | 自分で集めた資料を使う。選んだ分はそのセッション中だけ有効 |

### Unsplash のキーの取り方

1. <https://unsplash.com/developers> で無料アカウントを作る
2. 「New Application」でアプリを1つ作る（Demo のままでよい）
3. 表示された **Access Key** を、アプリの 設定 → Unsplash Access Key に貼って「接続テスト」

キーはこの端末の `localStorage` にだけ入る。Unsplash 以外のどこにも送られない
（そもそも送る先のサーバーが無い）。Demo キーは 1時間あたり50リクエストまでだが、
1リクエストで10枚まとめて取るので通常の練習では足りる。

Unsplash のガイドラインに従い、写真には撮影者のクレジットを表示し（セッション画面右上の ⓘ）、
写真を使った時点で download エンドポイントを1回叩いている。

## 練習メニューの中身と、その根拠

### 全体の設計

| 考え方 | アプリでの実装 | 出典 |
| --- | --- | --- |
| 意図的な練習 | 毎日の観察テーマを1つだけ提示し、終了直後にふりかえりを挟む | K. Anders Ericsson『Peak』 |
| 小さく始める | 最短3分・ワンタップ開始・連続日数の可視化 | BJ Fogg『Tiny Habits』/ James Clear『Atomic Habits』 |
| 観察の技能分解 | 輪郭／ネガティブスペース／比率と角度／明暗／全体把握、をドリルに1対1で対応させた | Betty Edwards『Drawing on the Right Side of the Brain』 |
| 形より先に動きと重心 | ウォームアップは必ず30秒前後のジェスチャーから | Michael Hampton / Mike Mattesi『FORCE』 |
| 観察だけでは描けない部位がある | 手や脚は知識の問題。解剖レッスンで「塊への置き換え」と「骨のでっぱり」だけを扱う | George B. Bridgman『Constructive Anatomy』(1920) |
| 混ぜる・少しずつ重くする | 1セッションに性質の違うドリルを混ぜ、回数に応じて時間と難度が自動で上がる | interleaving / progressive overload |

### ドリル

「見せ方の加工」がこのアプリの本体。頭が記号（＝「これは腕」）で処理してしまうのを、
表示を壊すことで物理的に防いでいる。

| ドリル | 写真の見せ方 | 何が鍛えられるか |
| --- | --- | --- |
| ジェスチャー | そのまま／20〜30秒 | 動き・重心・全体の流れ。細部を描く時間を奪うのが目的 |
| シルエット | ぼかし＋コントラスト | 目を細めたときに残る大きな塊。輪郭の凹凸 |
| ネガティブスペース | 2階調＋反転 | 物ではなく「すき間の形」。記号化の回避に最も効く |
| 輪郭線（コンター） | そのまま | 目の速度に手の速度を合わせる |
| ブラインド・コンター | そのまま（紙を見ないで描く） | 「上手く描こうとする補正」を切る |
| 比率と角度 | 4×4グリッド | 縦横比を測ってから描く癖。傾きの思い込みの修正 |
| 明暗3段階（ノタン） | 3階調にポスタライズ | 暗・中・明への仕分け。立体感の土台 |
| 逆さ模写 | 180°回転 | 「顔」「手」という認識を切って、線と角度そのものを見る |
| 記憶ドロー | 10秒後に隠れる（3秒ののぞき見が2回まで） | 形を頭に保持する力 |
| 塊取り（構造模写） | 解剖図版をそのまま | 箱・円柱・くさびへの置き換え。解剖レッスン用 |
| ランドマーク打ち | 実物写真をそのまま | 骨のでっぱりを先に点で押さえる。解剖レッスン用 |

ポスタライズは CSS では表現できないので、`index.html` に埋めた SVG フィルタ
（`feComponentTransfer` の `discrete`）を `filter: url(#f-posterize3)` で当てている。

## 解剖レッスン（手・骨盤と脚・足首と足）

観察ドリルには限界がある。**中に何が入っているか知らない部位は、見ていても描けない。**
目は見ているのに、脳が「いつもの下手な手」という記号に翻訳してしまうため。
そこで、描けない部位だけを潰すためのレッスンを別に用意した。

各レッスンの中身は3つだけ。筋肉の名前は出てこない。

1. **塊への置き換え** — 「手のひらの箱 → 拳の山の弧 → 親指の三角 → 指の階段」のように、描く順番として書いてある
2. **ランドマーク** — 体型や角度が変わっても位置が動かない骨のでっぱり。ここを先に点で打つと形が破綻しない
3. **よくある失敗と直し方** — 「くるぶしを左右同じ高さにする → 内が高く外が低い」など

読んだあと、そのまま同じ画面から練習に入れる。練習は

```
図版を塊で模写（3分×2） → 実物写真にランドマークを打つ（1分×2）
→ クロッキー（30秒×4） → 記憶で1枚
```

の順で、**知識 → 実物への適用**の流れになっている。
終了後のふりかえりには、その部位専用のセルフチェックが出る。
チェックが付かなかった項目は「次回の宿題」として記録画面に残る。

### 図版について

図版は **Wikimedia Commons** から実行時に検索して取得する（`js/commons.js`）。
ファイル名を直書きしないのは、消えたり改名されたりすると全滅するため。
ライセンスが PD / CC0 / CC BY / CC BY-SA のものだけを通し、
NC（非営利限定）と ND（改変禁止）は模写素材にしたくないので弾いている。

出典に使っている本はすべて著作権保護期間が満了している。

| 書名 | 著者 | 年 |
| --- | --- | --- |
| Constructive Anatomy | George B. Bridgman | 1920 |
| Anatomy of the Human Body | Henry Gray | 1918 |
| The Human Figure | John H. Vanderpoel | 1907 |
| Anatomie artistique | Paul Richer | 1890 |

**図版の中の文字は英語（一部フランス語）だが、読む必要はない。**
解説はすべて日本語で `js/anatomy.js` に書いてあり、図は形だけ見ればいい。

### レベルと段階的過負荷

通算セッション数でレベルが上がる（7 / 21 / 50 / 100回）。上がると

- ジェスチャーが 30秒 → 25 → 20 → 15秒 と短くなる（判断を速く）
- 長時間ドリルは 1.1〜1.4倍に伸びる（観察の解像度を上げる）
- ジャンルが解禁される（Lv.2で 顔・手、Lv.3で 布のしわ・建築）

## 操作

| キー | 動作 |
| --- | --- |
| Space | 一時停止／再開（説明画面では開始） |
| → | 次の写真へ |
| G | グリッドの表示切替 |
| F | 左右反転 |
| Esc | セッションを中断（そこまでの分は記録される） |

途中でやめても20秒以上やっていれば記録に残る。「1分でもやった日」を切り捨てないため。

## データ

| 中身 | 置き場所 |
| --- | --- |
| 設定・練習履歴・ふりかえりメモ | `localStorage` |
| 自分の絵の写真 | `IndexedDB`（長辺1000pxのJPEGに縮小して保存） |

外部に送信する通信は、写真を取りに行く Unsplash / Lorem Picsum へのリクエストだけ。
設定画面から JSON で書き出せる（書き出しにキーは含まれない）。

## ファイル構成

```
index.html                画面の骨組みと SVG フィルタ
css/styles.css
js/theory.js              ドリル定義・メニュー・観察テーマ・レベル設計（＝中身はここ）
js/anatomy.js             解剖レッスンの日本語解説（手／骨盤と脚／足首と足）
js/commons.js             Wikimedia Commons からPD図版を検索・ライセンス選別
js/session.js             セッションの進行役
js/images.js              写真の取得（Unsplash / Picsum / 端末内）と先読み
js/timer.js               カウントダウンと効果音
js/storage.js             設定と履歴、連続日数の集計
js/db.js                  自分の絵の保存（IndexedDB）
js/ui.js                  画面切り替えなどの小道具
sw.js                     アプリ本体だけキャッシュする Service Worker
```

メニューやドリルを足したいときは `js/theory.js` だけ触ればいい。
`MENUS` に並びを、`DRILLS` に「見せ方」を書けば、進行側は自動で対応する。
